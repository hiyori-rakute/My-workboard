# My Workboard V10.11

基于 V10.8 稳定版重做重复规则，避免 V10.10 的 Today / Routine 空白问题。

Routine / Kanban 共通：
- 每周指定星期使用 checkbox，可同时选择周二 + 周五。
- 每月指定日期。
- 每月最后一天。
- 每3个月，可设起算日期。
- 每年指定月份，可同时选择 4月 + 8月等。
- 同一任务可配置多个条件。
- OR：任意条件满足就执行，例如 每周五 OR 每月最后一天。
- AND：全部条件同时满足才执行。

V10.8 已稳定的 Today、Routine 布局、日历、图片、富文本不做结构性修改。
