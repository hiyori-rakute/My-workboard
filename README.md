# My Workboard V10.4

修复 / 新增：
- 所有富文本编辑器（Kanban / Project / SOP / Memo / Templates）：
  空白行可直接用 Backspace / Delete 删除。
- 保存或离开编辑框时会自动清理真正的空白 div/p/br 行。
- 每个富文本子任务新增：
  - ↪：把当前任务变成“上一条任务”的次级子任务
  - ↩：把当前任务提升一级
- 因此可以先创建 test1 / test2 / test3，再把 test3 一键归入 test2。
- 保留 ↑ ↓ 排序、📅预计开始、⏰预计完成、↳＋直接添加子任务、✕删除。
- 兼容 V8~V10.3 已保存的任务，打开后会自动补上层级按钮。
